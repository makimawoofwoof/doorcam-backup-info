Doorcam Backup

Privacy policy

Last updated: 26 September 2026.

Doorcam Backup is operated by its owner for personal use. It is not a public camera service.

Google Drive access

The application uses the owner's Google authorization to upload selected recordings, event information, database backups and redacted configuration backups. It lists and downloads backup files for playback and recovery, and removes files according to the owner's retention settings. These operations are directed at the application's backup folders.

The Drive permission can grant broader access than those folders. The application uses that permission for its backup functions, not to analyze unrelated Drive files. Authorization tokens are stored on the owner's device and are not published on this website.

Storage and sharing

Backup data is stored on the owner's equipment and in the owner's Google Drive. Google processes the stored data under its own policies. The application does not sell Google user data or use it for advertising. This website does not publish backup data.

Retention and control

The owner controls backup retention and can delete backups from Google Drive or revoke this application's access in Google Account settings. Revoking access stops future authorized operations but does not by itself delete existing backups.

This website

These static information pages contain no forms, analytics scripts or advertising. GitHub Pages hosts the site and may process visitor information under the GitHub Privacy Statement.

Contact

For questions about the application's Google access, use the developer support contact shown on its Google consent screen.
